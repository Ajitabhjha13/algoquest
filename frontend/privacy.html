AlgoQuest Privacy Policy

Last updated: October 2026

AlgoQuest is a personal DSA planner built and used by Ajitabh Kumar Jha. Only its owner can sign in. Anyone can explore it as a guest, and guest data never leaves the visitor's own browser.

What is stored

  • Planner progress (problems, warm-ups, lectures, notes, settings) for the owner's account, so it can sync across devices.
  • Basic profile from GitHub or Google at sign-in: name, email address and profile picture. No password is ever stored.
  • Security log of sign-in attempts: time, sign-in provider, device type and IP address, used to detect suspicious sign-ins.

Guests

In guest mode everything is saved only in the visitor's browser (localStorage). Nothing is sent to our server. If a non-owner tries to sign in, the attempt is blocked and only the security log entry above is kept.

Where it is stored

Data is stored in a TiDB Cloud database (Singapore) and processed by our API on Render (Singapore). Security alert emails are sent to the owner through Resend.

What we never do

  • No ads, no selling or sharing of data, no third-party analytics or tracking.
  • No access to your GitHub repositories or Google data beyond the basic profile listed above.

YouTube

The lectures feature uses the YouTube Data API to read a public playlist. The API key stays in the owner's browser only. See the Google Privacy Policy.
